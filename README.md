# mc-client

Just some mods and stuff so that my frens can sync with my server

## How to use

Run these in your 26.2 fabric game directory:

```
git init
git remote add origin https://github.com/Vishrut2403/mc-client.git
git fetch origin
git checkout origin/main -- mods schematics
```
To get updates later, just run:

```
git pull origin main
```
